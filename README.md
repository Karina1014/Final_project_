# 🏥 Vaccine Digitalization for Veterinary Clinics 🐶💉

## 📌 Description
This project aims to digitize vaccine control for pets, facilitating information management for veterinarians and veterinary clinics. The platform allows the registration, tracking, and validation of administered vaccines, ensuring secure access through 🔐 JWT authentication.

## 🚀 Technologies Used
The system is developed with a microservices-based architecture and utilizes the following programming languages:
- 🦫 **Go**: For efficient and scalable service management.
- 🐍 **Python**: Business logic implementation and GraphQL with FastAPI.
- 💎 **Ruby**: Data processing and background tasks.
- 🌐 **JavaScript**: Frontend and some backend integrations.

## ⭐ Key Features
- 🔐 **Secure authentication with JWT**.
- 👨‍⚕️ **User and veterinarian management**.
- 💉 **Vaccine registration and tracking**.
- 📊 **Generation of vaccination reports**.
- 🗄️ **Integration with relational and NoSQL databases**.

## 🏗️ Project Architecture
The project follows a microservices-based architecture and Clean Architecture principles. It is divided into the following modules:
- 🔐 **User authentication**: Access management using JWT.
- 🐾 **Owner and pet management**: Control of pet owners and their respective pets.
- 💉 **Vaccine management**: Registration and updating of administered vaccines.
- 🏥 **Veterinary clinic administration**: Information and management of veterinary professionals.

## 🛠️ Installation and Configuration
1. 📥 Clone the repository:
   ```sh
   git clone https://github.com/user/vaccine-digitalization-project.git
   ```
2. ⚙️ Configure the necessary environment variables.
3. 📦 Install dependencies for each service according to its technology:
   - 🦫 For Go:
     ```sh
     go mod tidy
     ```
   - 🐍 For Python:
     ```sh
     pip install -r requirements.txt
     ```
   - 💎 For Ruby:
     ```sh
     bundle install
     ```
   - 🌐 For JavaScript:
     ```sh
     npm install
     ```
4. ▶️ Start the services:
   ```sh
   docker-compose up -d
   ```
